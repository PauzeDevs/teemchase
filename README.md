# TeemChase Links

A gold-forward, mobile-first creator links website with a dedicated music streaming page.

## Files
- `index.html` — creator link hub
- `music.html` — streaming platform links
- `style.css` — shared responsive styling

## Run locally
Open `index.html` in a browser. The profile image currently resolves from the public Instagram handle through Unavatar; replace it with a locally hosted approved image if preferred.
